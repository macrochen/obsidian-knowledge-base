坦率的讲，对期权卖方来说，最怕的不是慢慢跌，慢慢跌你能扛、能 roll、能调整。最怕的是突然暴涨，尤其是那种跳空暴涨，你连反应的时间都没有，上方的裸卖 Call 直接把你送上天台。

后来我在 Tastylive 上翻视频的时候，看到了 Liz Dierking 讲一个策略，叫 Jade Lizard。

翡翠蜥蜴。

我当时的第一反应是，这什么鬼名字。但听完她讲完结构之后，我愣住了，这玩意也太骚了吧。

Jade Lizard 的结构其实很简单，就三条腿。先卖一个虚值的 Put，跟你平时裸卖 Put 一模一样，这是你的主要权利金来源。然后卖一个虚值的 Call，再买一个更远的虚值 Call。后面两条腿组合在一起，就构成了一个 Bear Call Spread，看涨信用价差。

等等，这不就是裸卖 Put 加一个看涨价差吗？

对，就是这么简单。但简单归简单，它解决了一个让我非常头疼的问题。

还记得我刚才说的，裸卖 Put 最怕暴涨吗？Jade Lizard 通过那个看涨价差，直接把上方的无限风险给锁死了。不管标的涨到天上去，你的最大亏损就是那个价差的宽度，减去你收的总权利金。

关键来了。

如果这个「总权利金」大于「价差宽度」呢？

举个具体的例子。假设波音 BA 的 IV Rank 到了44%，波动率比较高。我在63天到期的期权链上构建一个 Jade Lizard，卖190的 Put，卖215的 Call，买220的 Call。上方价差宽度是5块。

因为 IV 高，Put 端的权利金非常肥，整个组合收取的净权利金达到了5.50块。

5.50大于5。

那结果会怎样呢？意味着就算波音明天公告跟空客合并了，股价直接翻倍到300块，上方价差被击穿产生5块的最大亏损，但你期初收了5.50块，算下来你还赚0.50块，也就是每份合约50美金。

你没看错。标的翻倍了，你还在赚钱。

这就是 Jade Lizard 最核心的创新，它通过精确的数学计算，构建了一个「无风险的上行穹顶」。只要收取的净权利金大于等于价差宽度，上方就永远不可能亏钱。

这玩意被业内叫做「戴着头盔的宽跨式策略」，Short Strangle with a helmet。我觉得这个比喻太到位了，你还是在做宽跨式，还是在收双边权利金，但头上多了一个头盔，被逼空也砸不死你。

那问题来了，天下有这么好的事？

当然没有。

金融市场这东西，风险守恒。Jade Lizard 锁死了上方风险，代价是什么呢？代价就是下方的风险，跟裸卖 Put 完全一样，一点没少。

坦率的讲，如果你的标的跌穿了 Put 的行权价，你就得老老实实接盘。跌到零你就亏到零，跟持有正股没有任何区别。上方的看涨价差会变成废纸，但它本来就没什么价值，不影响你的盈亏。

所以 Jade Lizard 的本质，就是在裸卖 Put 的基础上，用多余的 Put 权利金「白嫖」了一个看涨价差，顺带消除了上行的逼空风险。下行该扛的你还得扛，但至少头顶安全了。

为啥 Put 端能提供这么多额外的权利金呢？

这里就得聊一个很重要的概念，隐含波动率偏斜，Put Skew。

1987年美股黑色星期一之后，整个期权市场对下行崩盘的恐惧被永久性地刻进了定价模型里。华尔街那些大基金，为了对冲手里的多头头寸，长年累月不计成本地买入虚值 Put。买的人多了，Put 的价格就被推上去了，形成了一个持续存在的「恐惧溢价」。

所以在等距离的虚值期权里，Put 的隐含波动率几乎永远比 Call 高。

Jade Lizard 就是在收割这个定价失衡。你卖出那个被恐惧情绪吹得特别贵的 Put，拿到手的权利金不仅够你自己用，还能顺带养一个看涨价差。这就是这个策略的套利本质。

说到这个，聊聊 Greeks。

我自己在做期权的时候，对 Greeks 的关注其实没有很多学术派那么重，但 Jade Lizard 的 Greeks 分布确实很有意思，值得聊一下。

首先是 Delta。整体组合是温和偏多的，因为裸卖 Put 有正 Delta，上方的看涨价差有负 Delta，两者一抵消，净 Delta 比单纯的裸卖 Put 小不少。这意味着如果标的小跌，看涨价差那边会帮你缓冲一部分亏损，回撤会比裸卖 Put 更温和一些。

然后是 Theta。作为卖方策略，时间衰减是你的朋友。Jade Lizard 收的是双端权利金，Theta 的绝对值比裸卖 Put 还要大。你每天睁开眼，账户里的浮盈就是在涨，这种感觉太爽了。

Vega 方面，组合是显著的负 Vega。两手卖出对一手买入，波动率下降对你非常有利。这也是为什么必须在 IV 高的时候建仓，因为 IV 一旦从高位回落，你会同时吃到 Theta 衰减和 Vega 下降的双重利润。

最后是 Gamma，这个是真正的隐形杀手。到期前最后几天，如果你的短腿行权价离标的价格很近，Gamma 会急剧膨胀。标的价格哪怕动一点点，你的 Delta 就会剧烈翻转，盯市盈亏上下乱窜。这是所有卖方策略的通病，但 Jade Lizard 因为有三条腿，Gamma 的波动比裸卖 Put 更复杂一些。

那什么时候做 Jade Lizard 最好？

我的经验是，IV Rank 大于50%的时候再动手。

IV 高的时候，期权链上各大行权价的权利金都被恐慌情绪吹得很大，你有足够的空间去挑选行权价，把短腿放在离现价更远、更安全的位置。同时满足「权利金大于价差宽度」这个硬条件也更容易。

IV 低的时候别碰。权利金太薄，你被迫把短腿往平值方向靠，或者把价差压得很窄，胜率和盈亏比都会急剧恶化。Reddit 的 r/thetagang 上有个哥们总结得特别好，低 IV 的时候做 Jade Lizard，就像为了捡一粒芝麻站在压路机前面。

说到 r/thetagang，这个社区里关于 Jade Lizard 和 Naked Put 到底谁更好，吵了得有好几年了。

支持 Jade Lizard 的人主要看中一个东西，资金效率。

在 Portfolio Margin 的账户里，你本来裸卖一个 Put 占用的保证金，再加一个 Bear Call Spread，几乎不增加额外的购买力消耗。因为系统看到你有多空对冲，会自动降低风险评估。也就是说你花同样的保证金，Jade Lizard 多收了一个价差的权利金，Theta 更大，接盘成本更低。

社区里有人做过对比测试，同一个标的，Naked Put 的 Theta 是1.85，Jade Lizard 能到2.0。如果最终接盘了，JL 的每股成本比裸卖 Put 还低几毛钱。

但反对的人也有道理。他们说，如果标的真的大涨了，裸卖 Put 虽然赚的权利金少，但至少不会在价差上亏钱。Jade Lizard 呢？上方价差被击穿，虽然因为「权利金大于宽度」不会真的亏，但你看着股价涨了50%，你只赚了0.50块，这种相对损失的心理落差是很折磨人的。

我自己的看法是，如果你对标的有强烈的做多信仰，裸卖 Put 是更纯粹的表达。但如果你的态度是中性偏温和看涨，同时又特别怕被轧空，Jade Lizard 确实是更好的选择。

聊到这，说一下具体的构建参数。

到期日的话，常规做法是45 DTE 左右，这个位置处于 Theta 曲线加速衰减的拐点，时间价值的收割效率最高，同时留给你调整的空间也够。Tastylive 还研究过7 DTE 的极短线玩法，但那个需要很精确的预期移动幅倍数计算，不太适合大多数人。

Put 的行权价，一般锚定在15到30 Delta 的位置。30 Delta 是一个很好的平衡点，大概有70%的单侧胜率，同时权利金也够肥。

Call Spread 的宽度，这是生死线。宽度必须严格小于总净权利金，否则策略就退化成了一个普通的双向无限风险的宽跨式，那还不如直接做 Strangle。Tastylive 的经典案例是收5.05的总信用，上方价差严格控制在5块以内。

止盈的话，我个人习惯在浮盈达到初始最大利润的25%到50%之间就平仓走人。你可能觉得这样太保守了，但期权卖方有一个铁律，永远不要扛到最后21天。最后三周是 Gamma 风险急剧膨胀的阶段，很多卖方就是在这个阶段把前面辛辛苦苦赚的利润全吐回去的。提前止盈，释放保证金，投入到下一个高概率周期里，资金周转率上去了，年化收益自然就上去了。

防守怎么做？

这是最关键的部分。

当标的暴跌，Put 被击穿的时候，你面临两个选择。

Reddit 上的草根派倾向于把组合拆开，先平掉上方已经盈利的 Call Spread 落袋为安，然后把下面流血的 Put 单独 roll 到更远的到期日和更低的行权价。

但 Tastylive 的专业研究员 Mike 和 Nick 强烈反对这种做法。他们的观点是，在恐慌中向下 roll 深度实值的 Put，根本拿不到什么净权利金，还会因为买卖价差扩大而进一步恶化成本。他们的建议是「向下拉扯未被测试的一端」，就是把上方闲置的 Call Spread 整体向下平移，移到更贴近现价的位置。在恐慌市中卖新的、更近的 Call Spread，能收到非常丰厚的权利金，从而大幅降低整体的盈亏平衡点，同时 Put 端的原始行权价防线不动。

我自己更倾向后者的做法。向下 roll Put 看起来是在防守，但很多时候是在用更大的亏损去换一个「看起来没那么糟」的成本基准，说到底是在加仓亏损方向。

说到极端行情，不得不提2020年3月的新冠熔断。

那段时间，整个市场像是被按了快进键的灾难片。能源、地产、旅游板块的股票跳空暴跌，30%、50%地往下砸。Jade Lizard 在这种级别的黑天鹅面前，上方 Call Spread 确实稳稳赚了，100%作废，全额落袋。但面对下方动辄腰斩的标的，这点杯水车薪的信用金根本挡不住。

IV 在那段时间垂直拉升，标的暴跌加 IV 暴涨，这就是传说中的「戴维斯双杀」，你的 Put 不仅内在价值爆亏，时间价值还因为 IV 飙升反而变贵了。

所以坦率的讲，Jade Lizard 不是万能的。它是一个高胜率策略，但高胜率不等于无风险。在真正的系统性崩盘面前，它的表现跟裸卖 Put 没有本质区别。

不过有意思的是，暴风雨过后，反而出现了一个 Jade Lizard 的变种玩法，叫 Reverse Jade Lizard，也叫 Twisted Sister，扭曲姐妹。

结构完全反过来。下方用看跌价差锁死最大亏损，上方裸卖 Call。逻辑是暴跌之后 Put 端的 IV 被吹到了历史级别的极端泡沫，卖看跌价差极其暴利，同时锁死了下方的深渊风险。适合在暴跌之后的震荡筑底期使用。

最后聊一个很容易被忽视的风险，保证金。

如果你用的是普通的 Reg T 保证金账户，而不是 Portfolio Margin，在市场暴跌的时候券商会突然大幅提高你的维持保证金要求。即使你的主观判断没变、你不想平仓，你的可用资金也会被清算系统抽干，最终触发强制平仓。

这个才是很多期权卖方真正死掉的原因。不是方向判断错了，而是被保证金扩张给挤死了。

铁律就是，任何时候都不要把购买力用满。至少留40%到50%的闲置现金，专门用来应对黑天鹅来袭时保证金的突然膨胀。Portfolio Margin 账户会好很多，因为系统基于压力测试来评估头寸，多空对冲后的保证金需求会显著降低。

写了这么多，最后总结一下我对 Jade Lizard 的理解。

它不是一个圣杯，不是一个百战百胜的策略。它是一个在特定环境下非常高效的波动率偏斜收割引擎。高 IV 的时候，做基本面健康的标的，它能给你提供比裸卖 Put 更高的资金效率和心理安全感，同时彻底消除逼空的噩梦。

但它保留了裸卖 Put 的全部下行风险，这一点必须刻进骨子里。

每次开仓之前，我都会问自己一个问题，如果这个标的明天暴跌30%，我能扛得住吗？如果答案是能，那我就做。如果答案是犹豫，那我宁可不做。

毕竟，金融市场深不见底的向下重力加速度，才是所有卖方策略从数学上无法掩盖的阿喀琉斯之踵。

敬畏之心，比任何策略参数都重要。
